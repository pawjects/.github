# 🐾 Who We Are

Pawjects is an independent open-source collective focused on creating modern software experiences across Android, Web and Telegram.

We enjoy building useful tools, experimenting with new ideas and transforming concepts into projects people can actually use.

Whether it's a lightweight utility, a polished interface, an Android customization project or a community-driven experiment, Pawjects exists to learn, create and share.

# 🤝 Contributing

Found a bug?

Have an idea?

Want to improve something?

Contributions of all sizes are appreciated.

```bash
# Fork the repository

# Clone your fork
git clone <your-fork-url>

# Create a feature branch
git checkout -b feature-name

# Commit your changes
git commit -m "Add awesome feature"

# Push your branch
git push origin feature-name
```

Then open a Pull Request 🚀
